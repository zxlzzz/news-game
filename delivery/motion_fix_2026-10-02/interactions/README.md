## Source observations, constraint scope and repair

The six generated clips exhibited unstable or flipped elbows under dense hand end-effector targets; the archives retain original local rotations that can be used to recover coherent body motion. Edited target positions disagree with full77 FK by 0.32–1.20 m, but that disagreement alone does not make an end-effector target invalid: the generator is asked to solve new hand positions while changing the parent arm chain.

All six requests also supplied sparse full-body position keys from the same archives. The installed `FullBodyConstraintSet.update_constraints` explicitly ignores the supplied global rotations; the hand constraints select Hand + MiddleEnd positions and Hand rotation. Thus unchanged ancestor rotations are not evidence that the worker constrained incompatible parent rotations. The original metadata do not record the final correction masks, and no controlled regeneration has isolated whether target reachability, target-group geometry, sparse body keys, or the generator's arm solution caused each flip. `constraint_scope.json` records the actual requested frames and this limit. The repair below restores coherent motion and task relationships; it is not a proven fix to the generator itself, and the archived generation inputs remain untouched.

`recover_sources.py` reconstructs the archived original whole-body local rotation motion, projects numerical rotation drift onto SO(3), and rebuilds every joint in the77-node hierarchy. Task grips use complete upper-arm/forearm/hand chains and stable anatomical elbow planes. All local/global rotations and positions are rebuilt together. Root paths, smooth roots, contacts, heading, body and legs come from the archived original motion. For the two loops only the final rotations, contacts and heading are repeated from frame0; the root progression is retained. There is no temporal smoothing or selected-frame freezing. Original shipped NPZ/meta bytes are under `before/`; archived generation inputs are untouched.
