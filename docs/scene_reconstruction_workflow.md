# 照真实地点做场景：三步流程

2026-09-28 和 Hsinlung 定下。目标：给一个地点（或在地图上框一块），脚本自己取资料，搭出一个完整场景。流程要自动化，不靠当地人口头描述补资料。尺度要真实，并且带上真实的地形和空间关系，不能只是把能认出来的东西摆在平地上。

三步严格按顺序做，每一步只做自己那部分：

## 1. 地基

地基是后面所有东西落脚的那个面，只包括：

- **坐标和高度基准**：原点、方向、米制、海平面。
- **地面的形状**：起伏、坡、平台。整平过的地方（楼基、球场、广场、路基）也算，但只记它的高度，不记它是什么。
- **水**：湖和海的水面与岸线。
- **路网**：把场地切成一块块的通道，包括车行道、步行街，和两头都连着路的长步道。路面的纵坡在这一步定。
- **场地边界**：可走范围之外是背景（远处的海、城市）。

画面上只有"路"和"非路"两种地面，再加上水。草地、铺装、广场、球场、园路、楼四周的铺装都不在这一步：它们是地上画的线，属于第二步。第一版把这些都画了，画面很乱，被 Hsinlung 否决。

## 2. 画线（静态布局）

在地基上画出所有固定物的边界和位置，比如草坪、铺装、广场、球场、楼、树、墙、灯。每件要定：占地轮廓或位置、朝向、长宽高、落地高度、入口和它连着哪条路。只有楼的占地轮廓不够，还要有楼高、入口朝向、入口标高。

形状用规整的（矩形、八角形、圆、顺着路的街块），细节交给装饰物。不要逐像素照着卫星图抠边界。

## 3. 建模

每个模型按一份有边界的说明做：预留尺寸、外观参考、落地点和连接点。建模的人不需要重做前两步。模型和预留尺寸冲突时，明确提出来解决，不要悄悄改地形或布局。做完按第二步摆放，检查尺寸、落地、入口和相互间距。

## 资料与记录

- 每一步用了什么信息、从哪来、缺了会怎样，记在这个地点的"复刻记录"里（现在只有 [山大威海校区](../research/sdu_weihai/复刻记录.md)）。资料出处和许可另记一份"来源"。
- 公开资料只能支持近似还原时，直接写明。输出更多像素、自动铺路，都补不出缺的地形细节。
- 允许目测估计：厘米级误差在这个游戏里看不出来。
