# 建模规范与参数（风格测试 2026-09-19）

适用：Godot 4.7.2，Forward+。工程里 `style/` 下的三个 shader 加上 `ink_builder.gd` 就是整套画风；`params/*.json` 存参数。
本文分两部分：一、模型要满足什么；二、参数是什么意思、现在拟合到多少。

---

## 一、建模规范

### 1. 尺寸与朝向（沿用旧规范）
- 单位米，原点在底面接地点，正面朝 +Z。
- 导出 GLB，带法线。

### 2. 颜色：只靠材质名，不靠贴图
- 模型不画颜色贴图。每个材质只表示"这是哪一类表面"，**材质名就是色槽名**，例如 `wall`、`trim`、`ground`、`window_lit`。
- 具体颜色写在场景参数的 `palette` 里，同一个模型换一个场景就换一套颜色，模型本身不用改。
- 现成素材（Quaternius 等）不用改名：在参数的 `slot_map` 里把它的材质名映射到色槽，支持通配符，例如 `"MI_RedBrick*": "wall"`。
- 没映射到的材质会退回"贴图平均色"，并在控制台打印 `UNMAPPED MATERIALS`。看到这行就去补映射。

### 3. 线：几何断在哪里，线就画在哪里
渲染器自动从几何里抽线，规则只有三条：
1. **开放边**画线：面片的边缘、两块互不相连的零件各自的边界。
2. **折角大于 `crease_deg`（现在是 35°）的边**画线：墙角、台阶棱、窗框。
3. **圆滑表面的外轮廓**随视角画线：栏杆柱、花盆、圆柱的侧影。

同一块连续平面上的三角面分界**不画**。所以建模时：
- **想要一条线** → 在那里真的断开几何（做成两块），或做出一个明显的折角。
  例：地砖缝要出线，就把地砖做成一块块分开的薄板；只想要一整块干净地面，就做成一整块。
- **不想要线** → 保持连续、共面，顶点焊接（相隔超过 0.5 mm 的缝会被当成开放边）。
- **倒角**：每一段倒角的折角都小于 35° 就不出线（比如 90° 分 3 段以上）；分 1～2 段会出双线。没把握就别倒角。
- **圆的东西**：一圈至少 12 段（每段 30°），否则每条棱都出线。
- **细节密度就是线的密度。** Quaternius 立面上每条装饰板缝都出了线，会显得密。想被看见的细节才建成几何，不想要的就别建。

### 4. 影子：必须是封闭的实体
- 影子由模型的**背面**投出（这样受光面不会挡自己，小物件的影子也不会被偏移吃掉）。
- 所以要投影的东西必须是**封闭体、法线朝外**。单张面片投不出影子；薄板要给厚度（≥ 2 cm）。
- 不需要投影的表面（玻璃、贴花）在色槽里标 `no_shadow`。

### 5. 贴花、花纹
- 地面标线、墙上的菱格花纹这类：做成贴在表面上的一张薄面片，**只用贴图的透明通道决定形状**（透明度小于 0.5 的地方被挖掉），颜色仍由色槽决定。
- 色槽标 `no_lines` 和 `no_shadow`。原作的花纹也是不描边的。

### 6. 窗和室内
- 玻璃单独一个材质，做成不透明。亮着的窗用 `flat`（不受光照影响，纯色）。
- 假室内、室内墙这些看不见的东西，色槽标 `hide`：不渲染、不出线、不投影。

### 7. 不要做的
- 半透明材质（除了上面的贴花挖空）。
- 用颜色贴图表达结构（砖缝、木纹）。要么建成几何，要么不要。
- 非等比缩放。线的法线计算假设等比缩放。

## 二、参数（`params/*.json`）

### 色调规则（`fill`）
每个表面按"受不受光、朝不朝光"分四种情况，颜色都是在色槽底色上乘一个系数（系数按 sRGB 数值写）：

| 情况 | 底色 | 排线 |
|---|---|---|
| 受光且正对光（N·L ≥ `band_ndl`） | 底色本身 | 无 |
| 受光但斜对光 | 底色 × `mid_mul` | `stroke_mid_mul`，覆盖率 `cover_grazing` |
| 被投影挡住的正对光面 | 底色 × `mid_mul` | `stroke_mid_mul`，覆盖率 `cover_shade` |
| 背光面，或被挡住的斜面 | 底色 × `dark_mul` | `stroke_dark_mul`，覆盖率 `cover_dark` |

排线固定在屏幕上，方向"/"，周期 `hatch_period_px` 像素。

### 其他
- `line`：`line_color` 线色，`width_px` 线宽（像素，不随远近变），`depth_bias` 线往镜头拉近的距离（米，防止被自身挡住）。
- `crease_deg`：折角超过多少度出线。
- `grade`：角落色晕。`tint_center` 是屏幕坐标（(0,1) 为左下角），`tint_radius` 半径，`tint_mix` 向色晕颜色混合的强度，`tint_multiply` 相乘的强度。
- `light`：`pitch` / `yaw` 光的方向，`shadow_bias` / `shadow_normal_bias` 阴影偏移。
- `sticks`：火柴人。线宽 4 px，实心头，不投影（2026-09-19 定）。

### 现在的两套值
- **`terrace.json`（黄色露台）**：五个颜色（亮面、中间调、暗面、两种排线）和线色，都是从原作截图的像素聚类取出来，再换算成相对底色的系数，已经和原作并排对比过。
  `mid_mul [.84,.73,.77]`，`dark_mul [.63,.25,.48]`，`stroke_mid_mul [.70,.42,.58]`，`stroke_dark_mul [.54,.12,.49]`，线色 sRGB 约 (189,37,74)，`band_ndl 0.5`，`hatch_period_px 5`（1080p 下），覆盖率 `0.15 / 0.4 / 0.4`，光 `pitch -35, yaw -55`。
- **`street_q.json`（城市关配色）**：颜色是从原作城市关截图聚类取的，**没有和原作做过并排对比**，是粗值。
  底色珊瑚红 (231,80,96)，`mid_mul [.85,.13,1.0]`，`dark_mul [.65,.09,.74]`，线色深紫 (62,9,104)，亮窗黄 (255,226,92)。

排线周期和线宽都是按像素算的：换分辨率的话，要按比例一起换。

## 三、已知问题
- 斜面上的阴影边缘会有一点锯齿，这是阴影贴图的精度问题。
- 长椅这类倒圆的边，原作有柔和过渡，我们是硬切。
- 贴花边缘会跟着贴图的磨损纹理有些毛糙。
