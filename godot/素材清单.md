## 完整场景用的模型（2026-09-24，不卡批次，越早到越好）

之后要一次搭完一个完整场景：**一条街 + 街对面的公园**，布局照旧项目（`assets/scene.json`）来，按米换算后大致如下，从楼到公园、由远到近：

| 地带 | 深度 | 上面有什么（旧项目的数量） |
|---|---|---|
| 临街楼 | — | 19 栋连排，住宅、老式底商、现代楼、便利店、书店、诊所；有的屋顶有水箱、太阳能板、广告牌 |
| 远侧人行道 | 约 3.5 米 | 行道树 13、路灯 7、垃圾桶 3、报刊架 2、消防栓 2、邮筒 2、售货机 2、电话亭 1、店招 15、公交站 2 |
| 自行车道 | 约 2 米 | 骑车的、骑电动车送外卖的 |
| 机动车道 | 约 9 米 | 公交、小汽车、出租车、摩托；斑马线 2 条，井盖 3、排水口 2 |
| 自行车道 | 约 2 米 | 同上 |
| 公园 | 约 11.5 米 | 草地；环形小径；**棋桌广场**（约 16 × 10 米的铺装椭圆，里面几张棋桌）；**喷泉小园**（约 26 × 14 米，中间喷泉直径约 5.7 米）；公园树 11、长椅 4、摊位 2、路灯 5、花坛 3、垃圾桶 3、报刊架/邮筒/消防栓各 1 |

整条长约 125 米。现在的画面看着不自然，很可能是场景太空，所以这一轮要的是**量和变化**，而不是个别模型更精细。已交的 `building_a`、`building_b`、`crosswalk` 已验收，算在内。

**楼（最要紧，先做）**

| 名字 | 要求 |
|---|---|
| 临街楼再做 6–8 栋 | 对应旧项目的几类：住宅（高、窄窗、阳台）、老式底商（二三层、一楼店面）、现代楼（大玻璃分隔、平直）、便利店、书店、诊所、咖啡馆、面包店。宽度要有差别：窄的 6–8 米，常规 10–12 米，宽的 14–18 米；2–6 层不等。任意两栋至少在三方面不同：高度、宽度、屋顶、窗的节奏、入口位置、一楼样式 |
| 屋顶配件 | 水箱、太阳能板、屋顶广告牌架，单独做成模型，可以摆到不同的楼顶上 |
| 转角楼 1 栋 | 两个面都临街（正面 +Z、右侧 +X 都是立面），放在街的一端 |
| 店招 3–4 种 | 挂在一楼门头上的招牌，宽 2–4 米，招牌上不写字 |

**人行道上的东西**

| 名字 | 要求 |
|---|---|
| 行道树 + 树池 | 树冠做成**实心块体**，不要贴图卡片叶子（卡片叶子在这套画风里只剩碎片，影子也不对）；树池是树根部地面的方框 |
| 街灯 | 高 6–7 米，灯臂朝 +Z |
| 垃圾桶、消防栓、邮筒 | 各 1 种 |
| 报刊架 / 报纸箱 | 1–2 种，可以几个排在一起，和"新闻"题材直接相关，可以做得显眼一点 |
| 自动售货机、电话亭 | 各 1 种 |
| 公交站 | 候车棚（带长凳）+ 站牌，棚下能站 3–4 人 |
| 护柱、自行车停车架 | 各 1 种 |
| 店门口立牌、咖啡馆外摆（小圆桌、椅子、遮阳伞） | 各自单独一个模型 |
| 空调外机、雨棚 | 挂在立面上的小件，给楼加细节 |

**公园里的东西**

| 名字 | 要求 |
|---|---|
| 公园树 2–3 种 | 比行道树大，一种宽冠、一种细高（像柏树），都要实心树冠 |
| 灌木、绿篱 | 实心；绿篱做成直段，可以沿公园边缘排一圈，留出入口 |
| 公园路灯 | 4 米左右的柱灯，和街灯区分开 |
| 长椅 | 座高 0.45 米、有靠背，朝向小径 |
| 棋桌 | 桌面 0.75 米，两侧凳子座高 0.45 米（第二批里那张） |
| 喷泉 | 直径约 5–6 米，圆形或八角形水池，中间一个喷水台；水面做成池里的一块平面，材质用新的 `water` 色槽 |
| 摊位 | 柜台 0.9 米，后面留出站人的空间（第二批里那个） |
| 花坛 | 长条形，高约 0.4 米，里面的植物是实心团块 |
| 铺装广场、小径 | 贴地的薄铺装块：一个椭圆广场（约 16 × 10 米）、一个圆形广场（直径约 12 米，围着喷泉）、小径的直段和弯段（宽约 2 米）。厚 2–3 厘米，边缘带一圈路缘石，材质 `concrete` |

**车（先只要模型，怎么动以后做）**

| 名字 | 要求 |
|---|---|
| 公交车 | 约 12 × 2.5 × 3 米，车门在车身右侧（按行驶方向） |
| 小汽车、出租车 | 约 4.5 米长；出租车车顶有灯牌 |
| 摩托 / 电动车、自行车 | 各 1 种 |

车头朝 +Z（和其他模型一样），摆进场景时再转；车窗用 `window`，车顶不要做成一整块亮色平板。

**地面贴花**

| 名字 | 要求 |
|---|---|
| 车道线 | 虚线、实线各一段，材质 `paint` |
| 自行车道标志 | 路面上的自行车图案，材质 `paint` |
| 井盖、排水口 | 贴在路面上的薄片或矮的实体 |

## 模型怎么做

规则、色槽名、统一尺寸、交付要求都在 `modeling/模型制作说明.md`。交给 ChatGPT 时附上：那份说明、本清单、`建模规范与参数.md`、`modeling/check_model.py`、`modeling/example_build_terrace.py`。

地面（车道、人行道、草地）由场景里的地面带生成，不需要模型。交互点（坐哪、站哪、门在哪）不用做进模型，我在类型库里标。
