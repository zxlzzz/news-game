# 模型制作说明

给负责建模的你看的。要做哪些模型见同时附上的 `素材清单.md`（只看"模型"那几行和"完整场景用的模型"一节）。
一起附上的还有：`建模规范与参数.md`（规则的完整原文，本说明是它的执行版，两者冲突以它为准）、
`check_model.py`（自检脚本）、`example_build_terrace.py`（用脚本建模的范例）。

---

## 1. 先知道画面是怎么来的

游戏**不使用模型的颜色和贴图**：
- 每个面按**材质名**换成配色表里的一个纯色，再按光照分成亮、中、暗三档，暗的两档加斜线排线。
- 描边是程序**从几何里自动抽出来的**，只画三种边：开放边（面片边缘、互不相连的零件各自的边界），折角大于 35° 的边，圆滑表面随视角出现的外轮廓。
- 影子由真实的方向光投出。

所以：**几何就是画面上的线，材质名就是颜色。**
相机是正交视角，从 +Z 那一侧往下俯视约 38°。现在一屏约 27 米高、1080 像素，也就是 1 米约 40 像素，线宽 1.5 像素。小于 5 厘米的细节在画面上只剩一团线。

## 2. 每个模型交付四样东西

1. **`<名字>.glb`**：名字用清单里的英文小写加下划线，例如 `building_a.glb`、`park_chess_table.glb`（文件名须与已有模型按不区分大小写比较，禁止覆盖）。
2. **`build_<名字>.py`**：生成这个 glb 的完整脚本，重跑能得到同样的结果。所有尺寸都写成脚本开头的具名常量（门高、层高、座高等），不要把数字散落在代码里。以后统一改模型，就是改常量重跑，所以这一项和 glb 同样重要。
3. **一段简短说明**，写清楚：
   - 长宽高；
   - 用了哪些色槽；
   - 原点在哪、正面朝哪；
   - 交互位置的大概坐标（座面、门口、柜台后面站人的位置等）；
   - 用了第三方素材的话，写来源链接和许可。
4. **`python check_model.py <名字>.glb` 的完整输出**，结果必须是 PASS。输出里的每条 WARN 都要在说明里交代是不是故意的。

## 3. 怎么建

- **首选用 Python 脚本从基本体拼**：trimesh + manifold3d + shapely，或者 Blender 的 bpy。写法参考 `example_build_terrace.py`（它的注释里写了它和正式交付有哪些不同）。
- 可以参考或改用网上的素材，但**只能用 CC0 的**。改完必须完全满足下面的规则：材质改名、去掉贴图、补成封闭体等。改造的每一步也要写进脚本。靠贴图才有细节的素材不要用。
- 风格：干净的块体、简洁的造型，像建筑模型或积木玩具。**想让玩家看见的结构才建成几何**；装饰缝、螺丝、小凹槽不要建。

## 4. 硬规则（check_model.py 会检查，任何一条不满足就是 FAIL）

| 规则 | 说明 |
|---|---|
| 单位是米 | 物体最长的一边在 0.02–200 米之间 |
| 原点在接地点 | 最低点 y = 0（误差不超过 1 厘米）；原点落在物体的占地范围内 |
| 朝向 | +Y 向上，正面朝 +Z |
| 只允许等比缩放 | 任何节点都不能有非等比缩放，也不能镜像（负缩放） |
| 法线、三角面 | 每个网格都带法线，全部是三角面 |
| 材质名 = 色槽名 | 只能用第 6 节表里的名字 |
| 贴图 | 只有 `paint` 可以带贴图，而且只用它的透明通道（alphaMode MASK），其余材质一律不要贴图 |
| 不许半透明 | 不允许 alphaMode BLEND |
| 导出不要压缩 | 不用 Draco、meshopt、KHR_mesh_quantization，Godot 读不了 |

## 5. 画面规则（脚本查不全，审阅时会看）

- **想要一条线**：在那里真的把几何断开（做成两块），或者做出大于 35° 的折角。
- **不想要线**：保持共面、连续，顶点焊接。缝隙超过 0.5 毫米会被当成开放边而出线。
- **倒角**：每一段的折角都小于 35° 才不出线，所以 90° 的角要分 3 段以上；只分 1–2 段会出双线。没把握就不倒角。
- **圆的东西**：一圈至少 12 段，否则每条棱都出线。
- **影子**：要投影的东西必须是封闭体，法线朝外。薄板至少给 2 厘米厚度；单张面片投不出影子。
- **细节密度就是线的密度**：立面上每条装饰缝都会变成一条线，画面会很密。
- **窗**：玻璃做成不透明的，材质用 `window`。
- **门**：门板单独做成一块，材质用 `door`。门洞后面必须封住（后面加一块墙或 `hidden` 面），不能透出背景。
- **看不见的内部**：要么不建，要么材质用 `hidden`。
- **贴花（地面标线、墙上花纹）**：做成一张贴在表面上的薄片，离表面 1–5 毫米，形状用贴图透明通道挖出来，材质用 `paint`。
- **树冠、灌木**：用几块实心多面体拼成团块，**不要用贴图卡片做树叶**。
- **零件要分出线**：想让两个零件之间出线，就把它们做成分开的块。

## 6. 色槽（材质名只能从这里选）

需要新的表面种类，就在说明里提出新名字和用途，经确认加进游戏之后才能使用。

| 色槽 | 用在哪 | 特殊画法 |
|---|---|---|
| `wall` | 楼的墙面 | |

| `trim` | 窗框、檐口、线脚、台阶 | |
| `trim_dark` | 深色的框、招牌底 | |

| `door` | 门板 | |
| `concrete` | 水泥、石头 | |
| `metal` / `metal_dark` | 浅色 / 深色金属 | |
| `wood` | 木头 | |

## 8. 原点和正面怎么定

- **一般物件**：原点放在底面中心。人使用的那一面朝 +Z，比如长椅坐的一面、摊位顾客站的一面。
- **楼**：原点放在正面墙脚的中点，正面墙面落在 z = 0；台阶、雨棚可以伸到 z > 0 那一侧。
- **转角楼**：同样原点在正面墙脚中点、正面朝 +Z；右侧（+X 那面）也是完整立面。
- **路灯**：原点在灯杆底部，灯臂朝 +Z。
- **车**：原点在车身底面中心，车头朝 +Z。
- **贴花**：原点放在中心，底面比 y = 0 高 1–5 毫米。（检查脚本允许最低点离地 1 厘米以内。）

## 9. 以前实际踩过的坑

- 用贴图表达砖缝、窗格：游戏不画贴图，这些细节会直接消失。
- 卡片树叶：画出来只剩碎片，影子也是错的。
- 门洞后面是空的：从门洞能看穿到背景。
- 导出时用了 KHR_mesh_quantization 压缩：Godot 直接导入失败。
- 原点在角上，或者模型沉到地面以下 1–25 厘米。
- 材质名是颜色名（`canary`、`charcoal`）：必须改成色槽名。
- 立面装饰板太多：每条缝都出线，画面很密。

## 10. 第一批审阅后补充的规矩（2026-09-24）

第一批的楼合规，但放进画面后看出下面几点，之后的模型都按这里做：

1. **窗和门要凹进墙里 0.4–0.5 米**，玻璃和门板在凹洞底部。立面的层次主要来自凹洞里的影子；只凹 0.2 米几乎看不出来。
2. **屋顶从镜头里看得到**，不要用一整块板把屋顶盖死。女儿墙顶上的压顶做成一圈；屋顶上放点东西，比如楼梯间、空调外机、水箱、天窗。第一批的两栋楼都是用一整块 `trim` 板盖住屋顶，成了画面里最亮的一大块。
3. **最亮的几个色槽只用在小面积上**：`trim`、`paint`、`accent`、`fabric` 是配色里最亮的一档。墙、屋顶、大块地面一律用 `wall` / `concrete`，否则大面会抢走整个画面。
4. **窗不要占满立面**：玻璃总面积大约不超过立面的三分之一。宁可窄而高，也不要又宽又大连成一片，深色的玻璃块多了立面会显得沉。
5. **细节集中在两个地方**：一楼（人眼高度的店招、雨棚、门框、立牌、橱窗框）和屋顶线（檐口、女儿墙、屋顶设备）。中间的楼层保持安静。
6. **楼和楼要有差别**：任意两栋至少在三方面不同，比如高度、宽度、屋顶、窗的节奏、入口位置、一楼样式。
7. **一次交多个模型时**，每个模型都要单独交齐第 2 节的四样东西。
