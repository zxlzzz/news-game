## 生成与验证

完整生成脚本在上一级目录；GLB 在 `../../models/`。楼的尺寸常量集中在脚本开头，两个脚本各自独立，不依赖其他建模脚本；斑马线只用 Python 标准库。

从仓库根目录运行（本次 Blender 5.2.1 LTS）：

```powershell
& 'D:\steam\steamapps\common\Blender\blender.exe' --background --factory-startup --python godot/modeling/build_building_a.py
& 'D:\steam\steamapps\common\Blender\blender.exe' --background --factory-startup --python godot/modeling/build_building_b.py
python godot/modeling/build_crosswalk.py
python godot/modeling/check_model.py godot/models/building_a.glb godot/models/building_b.glb godot/models/crosswalk.glb
```

[完整自检输出](check_model.txt)：三件均 **PASS，零 WARN**。A 为 1,166 三角面，B 为 1,150，斑马线为 2。建筑采用封闭几何，法线朝外，无贴图；节点没有非等比或负缩放。GLB 不使用压缩扩展。

已复跑全部生成脚本：三件 GLB 的 SHA-256 均与前次一致；另核对了建筑各网格的正体积和三角面与导出法线朝向一致。

可重开审阅场景（不修改默认游戏入口）：

```powershell
& 'D:\Godot\Godot_v4.7.2-stable_win64_console.exe' --path godot res://modeling/review_models.tscn
```

附加 `-- --review a` / `b` / `crosswalk` 可选单件；附加 `--shot <绝对PNG路径>` 保存截图并退出。

检查确认：门洞不透背景、窗为不透明色槽、退台和真实投影可见、斑马线 alpha 挖空正确。建筑背面与左侧按临街连排使用保持简洁实墙；未制作招牌文字和室内。当前光照下大面积正面有排线，截图沿用工程参数，未单独美化模型灯光。
