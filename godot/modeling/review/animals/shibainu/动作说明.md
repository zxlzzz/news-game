# 柴犬动作素材库

新增 **46 条**，其中 11 条循环，共 129.6 秒；另完整保留原模型的 12 条动作。只提供烘焙动作素材，没有行为或游戏动画控制逻辑。

[打开逐条播放页](review.html)。左侧面、右游戏角度；每条有动图和六阶段姿势图。单次动作播完后的重置属于预览重放，不是动画内跳变。

## 内容与使用

- `shibainu_motion_library.glb` 包含原网格、骨架、权重、原动作及所有新增片段。原模型静态数据、原动作 JSON 和原二进制前缀均逐项验证不变。
- 新增片段统一 `NG_` 前缀，30 fps，每根骨头仅平移/旋转关键帧；无辅助骨、运行时约束、骨头缩放或拉长。
- 所有位移均在原地动作内，身体的起伏属于姿势。片段的 `base_state` / `end_state` 记录在 GLB 动画 extras，衔接顺序见检查报告。
- 已烘焙临时解析 IK；程序接入时可直接播放，或只读骨架重新摆姿势。动作文件自身不会驱动游戏 AI。

## 验证与限制

- 独立读回 GLB，检查 30 fps 键帧及 60 fps 半帧插值，执行骨骼矩阵累乘和真实线性蒙皮。所有片段通过：支撑爪最大误差 0.055 mm；最低顶点最大穿地 0.182 mm。
- 循环首尾同姿；成套的坐/趴/睡/侧躺/嗅地进出片段检查衔接缝。完整数值见 `verify_report.json`，控制台输出见 `check.txt`。
- 骨架和低面数网格的限制依然存在：深折叠会有棱角，视觉检查不等于对所有三角面组合的自相交数学证明。
- 坐姿后爪向前收、略向两侧展开，跗关节随之调整；所有坐姿及坐下/起身/坐趴过渡使用同一后腿布局。
- 尾巴保持原卷尾外形，压尾不是把尾巴拉直。
- 后爪挠耳未交付：强行够耳会超出腿链长度。没有把失败试片算进数量。
- `model_check.txt` 保存通用模型检查；`animal_ink` 的色槽 FAIL 为任务指定例外，未改检查器。

## 重跑

`build_motions.py` 用 Blender 后台运行；`-- --preview` 生成逐帧预览；再用 Python + Pillow 跑 `make_previews.py` 生成播放页和动图。
`verify_motions.py` 用普通 Python + numpy 独立检查。脚本依赖 `../../animal_tools/` 和对应 `../../models/animal_*/`；请保留目录关系。`motion_specs.json` 是动作参数；原始 .blend 不用于新增动作的构建。
